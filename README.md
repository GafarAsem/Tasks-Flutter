# منظم الملاحظات

تطبيق منظم ملاحظات بسيط تم تطويره باستخدام Flutter و Dart.

## متطلبات تشغيل التطبيق

1. تثبيت Flutter على جهازك
2. الحصول على خطوط Cairo العربية ووضعها في مجلد `fonts` في جذر المشروع

## إضافة الخطوط العربية

لعرض النصوص العربية بشكل صحيح، يرجى اتباع الخطوات التالية:

1. قم بإنشاء مجلد `fonts` في جذر المشروع
2. قم بتنزيل خطوط Cairo من [Google Fonts](https://fonts.google.com/specimen/Cairo)
3. أضف الملفات التالية إلى مجلد `fonts`:
   - Cairo-Regular.ttf
   - Cairo-Bold.ttf

## تشغيل التطبيق

1. تأكد من إضافة الخطوط كما هو موضح أعلاه
2. قم بتشغيل الأمر التالي في الطرفية:
   ```
   flutter pub get
   flutter run
   ```

## ميزات التطبيق

- تسجيل الدخول وحفظ الحالة
- إضافة الملاحظات وحفظها محلياً
- عرض الملاحظات مع إمكانية الحذف
- تسجيل الخروج
